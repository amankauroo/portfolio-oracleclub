Images

Gmail only displays images that are hosted online. Paste a public image URL, or upload a file to preview it (uploads are not visible to recipients until hosted).

Gmail's dark mode (notably on Android) can invert images, turning black icons white and photos into negatives. This swaps the bundled images for versions that read correctly either way (blue icons, slate script, tinted photo). Upload the -dm.png files from assets/gmail_signature to your host too.

    Add it to Gmail

    1. Make sure every image uses a public URL (see the check above).
    2. Click Copy signature.
    3. In Gmail open Settings, See all settings, General, Signature, then create a new signature.
    4. Paste into the box (Ctrl+V or Cmd+V) and click Save Changes.
